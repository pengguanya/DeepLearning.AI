# DeepLearning.AI Courses

Learning materials, lab work, and projects from [DeepLearning.AI](https://www.deeplearning.ai/) short courses.

## Courses

| Directory | Course | Topics |
|-----------|--------|--------|
| `DeepLearning.AI_Agentic_AI_AndrewNg/` | [Agentic AI](https://www.deeplearning.ai/courses/) by Andrew Ng | Planning workflows, multi-agent systems, code-as-plan pattern |
| `DeepLearning.AI_Build_with_Andrew/` | Build with Andrew | Hands-on building projects (HTML games, interactive apps) |
| `DeepLearning.AI_Evaluating_AI_Agents/` | [Evaluating AI Agents](https://www.deeplearning.ai/short-courses/evaluating-ai-agents/) | Agent observability, evaluation-driven development, LLM-as-a-judge |
| `DeepLearning.AI_LangChain_for_LLM_Application_Development/` | [LangChain for LLM Application Development](https://www.deeplearning.ai/short-courses/langchain-for-llm-application-development/) | Prompts, memory, chains, Q&A, evaluation, agents |

## Structure

Each course directory contains:
- **Transcripts** — lecture transcripts (`transcript.txt`) organized by section
- **Labs / Notebooks** — code examples and hands-on exercises
- **CLAUDE.md** — course-specific instructions for the AI learning companion

## Learning Companion

This repo is designed to be used with [Claude Code](https://claude.ai/code) as an AI learning companion. Navigate into any course directory and Claude will:
- Explain concepts grounded in the actual course content
- Generate practice exercises from basic to advanced
- Help extend lab examples and build projects
- Connect ideas across courses and sections
